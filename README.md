
# 📊 Online Store Performance Analysis Dashboard

An interactive **Power BI dashboard** for analyzing e-commerce sales, profitability, customer segments, product performance, and regional trends.

## 📌 Project Overview

This project uses Microsoft Power BI to turn e-commerce data into interactive business insights. It brings key performance indicators (KPIs) and visual analysis together to help users explore sales performance, profitability, customer segments, and product categories.

The dashboard combines **Power Query for data preparation, DAX for business measures, and interactive visualizations** to support data-driven analysis.

## 🎯 Business Questions

The dashboard is designed to help explore questions such as:

- How do sales and profit change over time?
- Which product categories contribute most to sales?
- How does performance vary across customer segments?
- Which regions generate higher sales and profitability?
- How do order dates, regions, and categories affect key metrics?
- What patterns can be identified by filtering the dashboard?

## ✨ Key Features

- **KPI Cards:** View total sales, total profit, orders, customers, quantity sold, and profit margin.
- **Sales Analysis:** Explore sales performance and trends over time.
- **Profitability Analysis:** Examine profit and profit margin.
- **Customer Segmentation:** Compare performance across customer segments.
- **Product & Category Analysis:** Explore product and category performance.
- **Regional Analysis:** Compare sales and profitability across regions.
- **Interactive Slicers:** Filter results by order date, region, customer segment, and category.
- **Dynamic Visualizations:** Explore how dashboard metrics change with filters.

## 🚀 Getting Started

### Prerequisites

- Microsoft Power BI Desktop
- The project `.pbix` file
- The source dataset, if it is stored separately

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/AshnaKazii/Online-Store-Performance-Analysis.git
   ```

2. Open the project folder:

   ```bash
   cd Online-Store-Performance-Analysis
   ```

3. Open the `.pbix` file in Power BI Desktop.

4. If Power BI requests the source data location, update the data source path and refresh the dataset.

5. Explore the dashboard using its interactive slicers and visuals.
